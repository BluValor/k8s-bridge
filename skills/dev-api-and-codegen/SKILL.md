# API, Codegen, Packaging, and Parity Audit Workflow (`dev-api-and-codegen`)

## 1. Preconditions & Inputs

Before modifying API schemas, RBAC markers, or chart templates, or running a pre-PR parity audit, verify:
- **Working directory:** Repository root (`k8s-bridge`).
- **Required tools:** `go` (`1.26+`), `make`, `git`, `helm`; `make manifests` and `make generate` install `controller-gen` (`v0.21.0`) under `./bin/`.
- **Target artifacts:**
  - Canonical CRD Go types: `api/v1alpha1/workloadmixing_types.go`
  - Controller RBAC markers: `internal/controller/workloadmixing/workloadmixing_controller.go`, `internal/controller/slurmclientsync/slurmclient_controller.go`, `internal/controller/slurmjob/slurmjob_controller.go`
  - Kustomize bases & samples: `config/crd/`, `config/rbac/`, `config/manager/`, `config/default/`, `config/prometheus/`, `config/samples/`
  - Helm chart & example YAMLs: `helm/Chart.yaml`, `helm/values.yaml`, `helm/crds/k8s-bridge.x-k8s.io_workloadmixings.yaml`, `helm/templates/`, `docs/examples/`
- Read [references/kubebuilder-markers.md](references/kubebuilder-markers.md) for validation and RBAC marker syntax, and read [references/parity-checklist.md](references/parity-checklist.md) for the pre-PR source-to-derived parity matrix.

---

## 2. Guardrails

- **Do not edit generated files:**
  - `api/v1alpha1/zz_generated.deepcopy.go` (generated by `make generate`)
  - `config/crd/bases/k8s-bridge.x-k8s.io_workloadmixings.yaml` (generated by `make manifests`)
  - `helm/crds/k8s-bridge.x-k8s.io_workloadmixings.yaml` (copied from `config/crd/bases/` by `make manifests`)
  - `config/rbac/role.yaml` (generated by `make manifests`)
  - `PROJECT` (managed by `kubebuilder` CLI)
- **Helm RBAC sync required:** `make manifests` updates `config/rbac/role.yaml` and copies the CRD to `helm/crds/`, but it does **not** update `helm/templates/clusterrole.yaml`. Whenever `+kubebuilder:rbac` markers change, update `helm/templates/clusterrole.yaml` to match `config/rbac/role.yaml`.
- **Preserve status subresource and API group:** Keep `+kubebuilder:subresource:status` on `WorkloadMixing` (`k8s-bridge.x-k8s.io/v1alpha1`, `Namespaced` scope) so `WorkloadMixingReconciler` can patch `status.conditions`.
- **Keep `VERSION` synchronized:** If changing `./VERSION`, run `make version-sync` to update `helm/Chart.yaml`, `config/manager/kustomization.yaml`, `README.md`, `helm/README.md`, `docs/quickstart.md`, and `docs/existing-infra.md`.

## 3. Step-by-Step Procedure

### Step 1: Edit `WorkloadMixing` Go Types and Validation Markers
1. Open `api/v1alpha1/workloadmixing_types.go`.
2. Add or modify struct fields on `WorkloadMixingSpec`, `PartitionMapping`, `GenericResourceMapping`, or `WorkloadMixingStatus`.
3. Add JSON tags (`json:"<fieldName>,omitempty"`) and Kubebuilder validation markers (`+required`, `+optional`, `+kubebuilder:validation:MaxLength=...`, `+kubebuilder:validation:Pattern=...`).
   - Check [references/kubebuilder-markers.md](references/kubebuilder-markers.md) for validation and RBAC marker syntax.

```go
// +kubebuilder:validation:MaxLength=64
// +kubebuilder:validation:Pattern="^[a-zA-Z0-9_-]+$"
// +optional
DynamicNodeFeature string `json:"dynamicNodeFeature,omitempty"`
```

### Step 2: Update Controller `+kubebuilder:rbac` Annotations (If Permissions Changed)
1. Locate the `+kubebuilder:rbac` markers above `Reconcile` in:
   - `internal/controller/workloadmixing/workloadmixing_controller.go`
   - `internal/controller/slurmclientsync/slurmclient_controller.go`
   - `internal/controller/slurmjob/slurmjob_controller.go`
2. Add or update the marker with `groups`, `resources`, and `verbs`:

```go
// +kubebuilder:rbac:groups=k8s-bridge.x-k8s.io,resources=workloadmixings,verbs=get;list;watch;create;update;patch;delete
// +kubebuilder:rbac:groups=k8s-bridge.x-k8s.io,resources=workloadmixings/status,verbs=get;update;patch
// +kubebuilder:rbac:groups=jobset.x-k8s.io,resources=jobsets,verbs=get;list;watch;create;update;patch;delete
// +kubebuilder:rbac:groups=jobset.x-k8s.io,resources=jobsets/finalizers,verbs=update
```

### Step 3: Run Code and Manifest Generation
Run `make manifests generate` from the repository root:

```bash
make manifests generate
```

This command executes:
1. `controller-gen rbac:roleName=manager-role ... crd:generateEmbeddedObjectMeta=true ... output:crd:artifacts:config=config/crd/bases`
2. `cp config/crd/bases/k8s-bridge.x-k8s.io_workloadmixings.yaml helm/crds/k8s-bridge.x-k8s.io_workloadmixings.yaml`
3. `controller-gen object:headerFile="hack/boilerplate.go.txt" ...` (updates `api/v1alpha1/zz_generated.deepcopy.go` for pointer/slice/map/new-type changes; scalar fields produce no diff)

### Step 4: Synchronize `helm/`, `config/`, and Audit Pre-PR Repository Parity
Compare the Kustomize bases in `config/`, the Helm chart in `helm/`, and the example manifests in `docs/examples/` against [references/parity-checklist.md](references/parity-checklist.md):
1. **If RBAC permissions changed:** Compare `config/rbac/role.yaml` against `helm/templates/clusterrole.yaml` and update the rules in `helm/templates/clusterrole.yaml` so every API group, resource, and verb list matches.
2. **If manager CLI flags or environment variables changed in `cmd/main.go`:**
   - Update `config/manager/manager.yaml` (Kustomize deployment args).
   - Update `helm/templates/deployment.yaml` and `helm/values.yaml` (note: `helm/templates/deployment.yaml` templates `--leader-elect`, `--health-probe-bind-address`, `--metrics-bind-address`, and `--zap-log-level={{ .Values.manager.logLevel }}` without an `extraArgs` helper).
3. **If CRD fields changed or before submitting a PR:** Audit `config/samples/k8s-bridge_v1alpha1_workloadmixing.yaml` and all `WorkloadMixing` manifests in `docs/examples/` against `api/v1alpha1/workloadmixing_types.go` (see [references/parity-checklist.md](references/parity-checklist.md)).
4. **If `./VERSION` changed:** Run `make version-sync` to synchronize `helm/Chart.yaml` (`version` & `appVersion`), `config/manager/kustomization.yaml` (`newTag`), `README.md`, `helm/README.md`, `docs/quickstart.md`, and `docs/existing-infra.md`.

---

## 4. Verification

1. Verify that version sync, code generation, formatting, and static analysis succeed with zero uncommitted drift:

```bash
make version-sync manifests generate fmt vet lint
git diff --exit-code config/crd/ helm/crds/ config/rbac/role.yaml api/ \
  helm/Chart.yaml config/manager/kustomization.yaml README.md helm/README.md \
  docs/quickstart.md docs/existing-infra.md
```

2. Verify that `config/crd/bases/k8s-bridge.x-k8s.io_workloadmixings.yaml` and `helm/crds/k8s-bridge.x-k8s.io_workloadmixings.yaml` are identical:

```bash
diff -u config/crd/bases/k8s-bridge.x-k8s.io_workloadmixings.yaml \
  helm/crds/k8s-bridge.x-k8s.io_workloadmixings.yaml
```

3. Verify that Kustomize bases, sample manifests, and Helm templates build and render without errors:

```bash
make kustomize
./bin/kustomize build config/default > /dev/null
./bin/kustomize build config/samples > /dev/null
helm lint ./helm
helm template k8s-bridge ./helm --namespace k8s-bridge-system > /dev/null
```

4. Run the unit and `envtest` test suite to confirm updated CRDs load into `envtest`:

```bash
make test
```
